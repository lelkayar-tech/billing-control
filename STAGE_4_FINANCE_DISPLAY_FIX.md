# Billing Control v2 — устранение дублирования платежей

Дата: 28.07.2026

## Что исправлено

- Из единой таблицы счетов и оплат удалена колонка «Оплачено».
- Эта колонка повторяла суммы платежей, которые уже отображаются по отдельности
  в колонке «Оплаты».
- В строке счёта остаются:
  - номер и содержание счёта;
  - сумма счёта;
  - связанные платежи с датами, комментариями и действиями;
  - остаток;
  - срок оплаты;
  - действия со счётом.
- Если по счёту есть несколько платежей, они по-прежнему располагаются друг
  под другом напротив этого счёта.
- Колонка «Оплаты» стала шире за счёт удалённой дублирующей колонки.

## Что не изменилось

- Сумма всех платежей по счёту продолжает использоваться для расчёта остатка.
- Статусы «ОПЛАЧЕНО», «ПРОСРОЧЕНО» и «ОЖИДАЕТ» рассчитываются по прежним
  правилам.
- Добавление, редактирование и удаление счетов и платежей сохранены.
- Схема, функции и рабочие данные Supabase не изменялись.

## Проверка

- 35 unit-тестов — пройдены;
- синтаксис и грамматика Python 3.10 — корректны;
- в HTML отсутствуют заголовок и отдельное значение «Оплачено»;
- колонка «Оплаты», остаток и все финансовые действия сохранены.
