# Billing Control v2 — дата отправки приложения

Дата: 28 июля 2026 года.

## Исправленная ошибка

После добавления редактирования даты подписания строка «Отправлено» осталась
только для просмотра. Поэтому в редакторской версии у двух соседних этапов
приложения были разные возможности: дату подписания можно было вводить через
карандаш, а дату отправки — нельзя.

## Что изменено

- Рядом со строкой «Отправлено» добавлен такой же карандаш, как у строки
  «Подписано».
- По карандашу открывается календарь с кнопками «Сохранить» и «Отмена».
- Дата сохраняется в `applications.sent_at`; пустое значение позволяет
  очистить ранее введённую дату.
- Обе даты приложения теперь формируются общей функцией интерфейса, чтобы
  расположение и поведение соседних строк оставались одинаковыми.
- Сообщения форм «Отправлено» и «Подписано» получили разные HTML-идентификаторы.

## Сохранение и защита

- Дата отправки проходит серверную проверку формата и диапазона.
- Обновление Supabase ограничено конкретным `applications.id`.
- После обновления строка повторно читается, чтобы подтвердить сохранённое
  значение.
- В `APP_MODE=read` карандаши и календари дат приложения не формируются.
- Схема и существующие строки Supabase не изменялись.

## Проверка

- Проверена отрисовка карандаша, календаря и кнопки сохранения для
  «Отправлено».
- Проверено фактическое сохранение `sent_at` на тестовом объекте Supabase и
  контрольное чтение результата.
- Проверено сохранение уже добавленного редактора «Подписано».
- Пройдены 50 unit-тестов и проверка синтаксиса Python.
