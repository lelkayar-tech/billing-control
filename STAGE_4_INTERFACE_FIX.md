# Billing Control v2 — исправление интерфейса этапа 4

Дата: 25.07.2026

## Причина

После успешного сохранения периодов или фотоотчёта страница полностью
перезагружалась. При новой загрузке все записи создавались свёрнутыми, поэтому
пользователю приходилось повторно искать и раскрывать только что изменённую
запись.

## Исправление

- Перед перезагрузкой сайт запоминает идентификатор текущего приложения.
- После загрузки эта запись автоматически раскрывается.
- Страница прокручивается к её основной строке.
- В раскрытой записи повторно показывается сообщение о результате операции.
- Поведение применяется к сохранению периодов, сохранению фотоотчёта и
  удалению строки фотоотчёта.

## Безопасность данных

- SQL-миграции не добавлялись.
- Схема Supabase не изменяется.
- Рабочие данные Supabase не изменяются при установке исправления.
