# Billing Control v2 — равные колонки формы счёта

Дата: 28 июля 2026 года.

## Исправленная ошибка

- Неравномерная сетка связывала ширину полей двух строк:
  - широкое «Содержание» делало таким же широким «Окончание услуг»;
  - узкая «Сумма» одновременно сжимала «Срок оплаты».
- Обе строки формы теперь состоят из трёх равных колонок.
- «Срок оплаты» занимает треть финансового блока, а не узкую правую колонку.
- Значок календаря больше не должен обрезаться правой границей поля.

## Что сохранено

- Продолжение номера счёта по существующей серии:
  `ОМ-13290/1 → ОМ-13290/2`.
- Редактирование дат отправки и подписания приложения.
- Сохранение счетов, платежей, периодов и фотоотчётов.
- Режим клиента только для чтения.

## Проверка

- Проверено точное правило `repeat(3, minmax(0, 1fr))`.
- Проверено отсутствие прежних пропорций широкой центральной и узкой правой
  колонок.
- Пройдены 54 unit-теста.
- Рабочие данные, схема Supabase, GitHub и Render не изменялись.
