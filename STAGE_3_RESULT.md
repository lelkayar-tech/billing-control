# Billing Control v2 — результат этапа 3

Дата: 25.07.2026

## Режимы приложения

- Добавлена поддержка `APP_MODE=edit` и `APP_MODE=read`.
- Пустое, неизвестное или ошибочное значение безопасно включает `read`.
- Для локальной версии редактирование включается только явным
  `APP_MODE=edit`.
- Текущий режим показывается в шапке интерфейса и в ответе `/health`.

## Серверная защита

- В `read`-режиме сервер блокирует все HTTP-методы, которые могут изменять
  данные: `POST`, `PUT`, `PATCH`, `DELETE` и другие небезопасные методы.
- Защита действует централизованно, поэтому автоматически распространяется
  на будущие изменяющие маршруты.
- Разрешённые методы просмотра: `GET`, `HEAD`, `OPTIONS`.
- При блокировке сервер возвращает HTTP `403`.

## Проверка

- Unit-тестами проверены `edit`, безопасный fallback в `read`, разрешённые
  методы просмотра и блокируемые изменяющие методы.
- Выполнена проверка синтаксиса всех Python-файлов этапа.

## Границы этапа

На этом этапе:

- Supabase и её схема не изменялись;
- данные не изменялись;
- CRUD-маршруты и формы ещё не добавлялись.
